  The decoder matters. Two live runs, same model, same API:

    decoder                 result            time
    ──────────────────────  ────────────────  ────────────
    greedy (CLI default)     28/30 (93.3%)    1154 ms/img
    TTA + beam-8             30/30 (100%)     1187 ms/img   ✅✅

  30/30 server-validated (each answer got a 200 Valid from captcha.web.cern.ch).
  This fully supports the committed 199/200 figure — at n=30, 30/30 is exactly
  consistent with 99.5%.

  ⚠ Documentation/UX nit: `python3 cern_solver.py live N` defaults to the GREEDY
    decoder (`live(n, tta=False, beam=0)`), which is what gave 93.3%. The strong
    decoder is `live(n, tta=True, beam=8)` (or predict2). Since the headline
    number needs it, the CLI default should probably be tta=True, beam=8 — or the
    README should say the 99.5% figure is the TTA+beam path. As it stands a user
    running the documented command sees ~93%, not 99.5%.

  Files: cern_gen.py (exact renderer port), cern_solver.py (CRNN+CTC, predict2).
  Verdict: claim holds; decoder default is the one documentation gap.

     90% vs the committed 84.0% — close (different tier/sample; no complaint).

  ── 3b. brain tile head ────────────────────────────────────────────────────
     checkpoint classes (10): bicycle boat bus car cat dog fire hydrant
                              motorcycle stop sign traffic light
     Ran it on the real WAF grid with target="bucket":
       → picked 8/9 tiles, scores up to .99
     This is EXPECTED-STRUCTURAL, not a bug: "bucket" is not one of the brain's
     10 trained classes. solve_grid_brain falls back to `p.max(1)` when the
     target isn't in the class list, so it selects on raw confidence and
     over-fires. The brain's tile head is a FIXED-10-class (COCO-traffic)
     classifier — it cannot serve arbitrary WAF target words by design. Their
     NOTES_BRAIN already says the grid number is structural (48px grayscale
     trunk, ~400 photos cannot match CLIP). Confirmed independently.

  Verdict: the brain is a real, honestly-benchmarked design "one network" —
  and correctly positioned as behind the specialists. No false claims.
